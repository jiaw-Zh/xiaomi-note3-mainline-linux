# 小米 Note 3 (jason) 主线 Linux 电源保护与服务器待机规范

## 1. 背景与核心风险

将 2017 年生产的旧手机（机龄近 9 年的高压锂聚合物电池）作为 7×24 小时长期通电的 Linux 服务器，存在两大致命隐患：
1. **长期高压浮充（4.2V~4.4V）**：导致电解液氧化分解，极板析氧产气，短时间内引起电池鼓包顶爆屏幕；
2. **粗暴浅循环充放电**：若仅采用外置定时插座（充到 80% 拔电，降到 40% 通电），电池长期处于高温下的浅循环充放状态，寿命数月即尽。

## 2. 四层纵深防护体系架构

本项目在 Linux 7.0 主线内核上实现了首个针对高通 PM660 芯片的**硬件级旁路直供（Bypass Mode）**方案：

### 第一道防线：硬件电气限压
- **原理**：高通 PM660 芯片具备 `FLOAT_VOLTAGE_CFG` 寄存器。
- **机制**：通过在设备树或驱动中设置设计上限，硬件 PMIC 在达到设定阈值时自动截止，杜绝高压浮充。

### 第二道防线：内核驱动硬件旁路（Bypass Mode）
- **驱动位置**：`drivers/power/supply/qcom_smbx.c`
- **原厂缺陷**：原主线驱动将 `status=0` 错误映射到 `USBIN_SUSPEND_BIT`，导致关闭充电时把外部 USB 供电也直接切断。
- **修复方案**：暴露 sysfs 接口 `/sys/class/power_supply/pm660-charger/charging_enabled`，直达底层 `CHARGING_ENABLE_CMD (0x42)` 寄存器的 `CHARGING_ENABLE_CMD_BIT`：
  - 写入 `0`：切断向电池灌入电流（电池充放电流归零）；
  - 主板母线：外部 USB 5V 正常供电系统（`online=1`），实现真正的硬件旁路直供！
  - 备用 UPS：电池 BATFET 保持闭合连通，若外部拔电，电池毫秒级无缝接管供电，不关机猝死。

### 第三道防线：系统态电池守护进程
- **服务**：`/usr/local/bin/battery-guardian.sh`（OpenRC `battery-guardian`）
- **逻辑**：
  - 上限（55%）：电量达到 55%（约 3.85V 最佳中位保存电压）自动切入旁路直供；
  - 下限（45%）：断电消耗至 45% 重新允许慢充；
  - 紧急熔断：电池温度 ≥ 45℃ 时强制断充。

### 第四道防线：服务器节能待机与电源键调优
- **背光控制**：屏幕息屏时背光电流降为 0，发热清零；
- **防误触关机**：将 `/etc/acpi/PWRF/00000080` 改写为背光开闭逻辑，短按电源键实现物理一键息屏与唤醒，彻底告别误触关机。
