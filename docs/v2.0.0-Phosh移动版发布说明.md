## 🎉 Xiaomi Mi Note 3 (jason) Mainline Linux v2.0.0 Release (Phosh Mobile Edition)

### 🚀 核心更新亮点 (Highlights)

1. **纯脱机独立冷启动与 Initramfs 去死锁（架构级重构）**：
   - 彻底解除引导阶段对电脑 USB 虚拟串口（`ttyGS0`）的同步阻塞；
   - 无论插在电脑、车载电源、普通充电器还是充电宝，开机 1.3 秒内快速自主切根，20 秒全自动进桌面，告别“必须连电脑才能开机”的历史依赖。

2. **SDM660 + WCN3990 WiFi 稳定性架构重构（两大补丁打通）**：
   - **Patch 0002**：强制覆盖扫描控制标志为 `0x82e`，根治 WCN3990 搜网即死锁（PC=0xb00a5d08）的固件空指针缺陷；
   - **Patch 0003**：解决断开/切换热点时 WCN3990 固件生命周期断言崩溃（`Asserted in wlan_vdev.c:_w`），推迟 `vdev_down` 至 peer 完全注销，实现 2.4GHz / 5GHz 频段随时平滑切换与实时搜网零崩溃。

3. **OEM 真实物理 MAC 动态提取与三层铁壁固化**：
   - 动态从高通 `persist` 原厂底层提取 6 字节二进制 MAC 地址，杜绝硬编码个人隐私；
   - 攻克 `ath10k_snoc` 驱动上电晚于脚本的时序差，通过 `systemd.link` + NetworkManager 约束 + 后台看门狗自愈进程，保证冷启动 100% 自动死锁绑定路由器固定 IP，彻底根治 MAC 漂移。

4. **Debian 12 + Phosh 原生触控移动桌面与常用应用全内置**：
   - 采用 Wayland 合成器 `phoc`，1080×1920 竖屏原生 KMS 输出，2x 缩放适配 5.5 英寸视网膜高分屏；
   - 搭载 `squeekboard` 移动虚拟软键盘，点击输入框自动弹出；
   - 预装系统设置（`gnome-control-center`）、文件管理器（`nautilus`）、网页浏览器（`epiphany`）、触控终端（`kgx`）；
   - 内建 `pwrkey-handler` 守护服务，短按电源键实现物理背光毫秒级息屏/亮屏，超低功耗待机。

5. **Adreno 512 GPU 开源硬件加速（Freedreno + Mesa）**：
   - 完整打通 `/dev/dri/card0` 与 `renderD128`，加载 `msm_dri.so` Gallium 驱动；
   - OpenGL ES 2.0 / 3.0 全硬件加速渲染，桌面滑动与窗口动画丝滑流畅。

6. **芯片级硬件断充与四层电池保护（服务器级守护）**：
   - 启用 PM660 芯片 `0x42` 硬件断充接口与 3.95V 物理限压；
   - 长期插电 5V 旁路直供主板，电池充放电流归零，杜绝鼓包；
   - 电池作为断电 UPS 随时并联在线，拔掉外部电线毫秒级无缝接管供电。

### 🛠️ 快速刷入指南 (Quick Flash Guide)

#### 步骤 1：刷入 boot 分区
手机长按「音量下 + 电源键」进入 Fastboot 模式，连接电脑后执行：
```bash
fastboot flash boot boot-xiaomi-jason-debian-phosh-v2.0.img
```

#### 步骤 2：解压 rootfs 到系统根分区（p71）
将 `rootfs-debian12-phosh-jason-v2.0.tar.gz` 解压至手机的 `linux` 分区（`/dev/mmcblk1p71`）：
```bash
# 格式化目标分区（若尚未格式化）
mkfs.ext4 -F -L "linux" /dev/mmcblk1p71

# 挂载并解压
mount /dev/mmcblk1p71 /mnt
tar -xzf rootfs-debian12-phosh-jason-v2.0.tar.gz -C /mnt/
umount /mnt
```

#### 步骤 3：重启开机
```bash
fastboot reboot
```
手机将在 20 秒内自动进入 Phosh 移动桌面！
默认普通用户：`jason`（无密码，支持免密 `sudo`）。
可通过串口（COM 虚拟串口 `ttyGS0`）或连接同一 WiFi 后通过 SSH 直连管理。
